// 05 — guarantees

Local-first, for real.

✓No cloud account

Everything in ~/.network-jobs/ — connections, corpus, profile, prefs, resume. No hosted API exists.

✓Your data stays home

// 06 — faq

Asked often.

+Does anything get uploaded anywhere?
No. Profile, resume, and connections live in ~/.network-jobs/ and are never sent to a remote API.
+Which agents work?
Any agent that can read a skill file and run a local command — Claude Code, Cursor, Codex, OpenCode, Muse, Pi, Gemini CLI, Hermes, Grok Bot, and others. setup --agent auto links everything it detects, Muse included via the shared ~/.agents/skills.
+Does it suit long-running agents?
That's what local files are for. Triage batches, corpus shards, and manifest.json persist between runs, so a background agent — Muse's persistent agents, say — resumes exactly where it left off. Nothing lives in a cloud queue that can time out.
+Do I need LinkedIn Premium?
No. Free export: Settings → Data privacy → Get a copy of your data → Connections only. Then network-jobs import ~/Downloads/Connections.zip.
+Which model should I use?
Yours. Stronger for discovery; mid-tier is usually enough for search and drafts.
+Does it message people for me?
Never. It drafts a forwardable intro naming a real mutual. You review, you send.
+What does it cost?
Free and MIT-licensed. You pay only for your own agent's tokens.
+Is there a zero-install option?
Yes — npx --yes @hirefrank/network-jobs@latest setup --agent auto runs setup with no global install. The launcher still lands on ~/.local/bin, so the network-jobs command sticks around.
